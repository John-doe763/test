# Daylight

A small, responsive task planner built with plain HTML, CSS, and JavaScript. It runs entirely in the browser; tasks are saved in local storage, so no account or backend is needed.

## Try it

Open `index.html` in a browser, or serve the folder locally:

```sh
python3 -m http.server 4173 --bind 0.0.0.0
```

Then visit `http://localhost:4173`.

## What you can do

- Add tasks with a note, priority, and due date
- Mark tasks complete, edit them, or delete them
- Search and filter your task list
- View Today, Upcoming, and Completed tasks
- See a live daily progress summary

Everything is stored in the browser under `daylight.tasks.v1`. Use your browser's local storage controls to reset the demo.
